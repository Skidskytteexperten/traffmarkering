# Skidskytteexperten – Träffmarkering

Ett enkelt digitalt verktyg för skidskyttar och tränare för att registrera och spara träffbilder.

## Funktioner

- Markera träffar direkt på tavlan
- Automatisk numrering i skottordning
- Upp till 8 träffar per serie
- Spara tidigare serier
- Visa sparade träffbilder
- Exportera sparade serier
- Fungerar på mobil, surfplatta och dator

Aktuella träffar visas med rosa markeringar och tidigare sparade serier med gula markeringar.

## Använd Träffmarkering

Öppna verktyget här:

https://skidskytteexperten.github.io/traffmarkering/

## Om lagring

Sparade serier lagras lokalt på användarens enhet/webbläsare. De synkroniseras inte automatiskt mellan olika enheter.
